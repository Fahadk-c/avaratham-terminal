# Malayalam Fail Sounds

A VS Code extension that plays a random short sound clip whenever a command in
the integrated terminal finishes with a **non-zero exit code**. Your build
breaks, your test fails, your `git push` gets rejected — and you hear about it.

## How it works

The extension listens to the stable Terminal Shell Integration API
(`vscode.window.onDidEndTerminalShellExecution`). When a command reports a
non-zero exit code, it picks a random clip from a sounds folder and plays it.

- **No repeats back-to-back** — the clip that just played is excluded from the
  next draw (as long as there is more than one clip).
- **Cooldown** — a configurable minimum gap between triggers so a burst of
  fast failures doesn't turn into a wall of noise.
- **Playback** — a reused webview panel with an `<audio autoplay>` tag. This
  works the same on macOS, Linux and Windows, with no dependency on system
  audio CLI tools like `afplay`, `aplay` or `ffplay`.

> Terminal shell integration must be active for the extension to see exit
> codes. It is enabled by default in recent VS Code versions for bash, zsh,
> fish and PowerShell.

## Running it locally

```bash
npm install
npm run compile
```

Then press <kbd>F5</kbd> in VS Code to launch the **Extension Development
Host** — a second VS Code window with the extension loaded. Open a terminal in
that window and run something that fails, e.g.:

```bash
exit 1
```

Use `npm run watch` instead of `npm run compile` if you want TypeScript to
recompile on every save while you work.

## Sounds

The repo ships with five synthesized placeholder tones in
`sounds/malayalam/`, generated by a pure-Node script (no `ffmpeg`/`sox`
needed):

```bash
npm run generate-placeholders
```

They exist only so the extension has something to play out of the box. To use
real clips, either:

1. Drop `.mp3`, `.wav` or `.ogg` files straight into `sounds/malayalam/`
   (and delete the `placeholder-*.wav` files), or
2. Point the extension at any folder on disk via the
   `malayalamFailSounds.soundsFolder` setting.

Keep clips short — 1 to 3 seconds — so they don't bleed into your next
command.

## Commands

Both are available from the Command Palette (<kbd>Cmd/Ctrl</kbd> +
<kbd>Shift</kbd> + <kbd>P</kbd>):

| Command | What it does |
| --- | --- |
| `Malayalam Fail Sounds: Toggle On/Off` | Flips the `enabled` setting globally |
| `Malayalam Fail Sounds: Play a Random Test Sound` | Plays one clip immediately, so you can check audio works |

## Settings

| Setting | Type | Default | Description |
| --- | --- | --- | --- |
| `malayalamFailSounds.enabled` | boolean | `true` | Turn sound-on-fail on or off. |
| `malayalamFailSounds.cooldownMs` | number | `2000` | Minimum milliseconds between two triggers. |
| `malayalamFailSounds.soundsFolder` | string | `""` | Absolute path to your own clips folder. Empty means use the bundled `sounds/malayalam`. |

Changing `soundsFolder` reloads the sound pool immediately — no window reload
required.

## Copyright note on audio

The bundled placeholders are generated sine tones and carry no rights issues.
Any real audio added later is a different matter: **only add clips you
actually have the rights to use and distribute**, especially before publishing
this extension to the VS Code Marketplace or sharing the repo publicly. Film
dialogue, music and other commercial recordings are usually not okay to
redistribute. Keeping your personal clips outside the repo — via the
`malayalamFailSounds.soundsFolder` setting — sidesteps the problem entirely.
